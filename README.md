# Diabetes Risk Predictor

## Overview

Diabetes Risk Predictor is a machine learning application designed to estimate diabetes risk based on user-provided health information.

The project focuses on transforming a trained machine learning model from a class project into a complete software application with a backend API, frontend interface, and development workflow.

## Project Goals

- Integrate the trained diabetes risk prediction model into an application
- Build a backend API for model inference
- Create a user-friendly frontend interface
- Implement testing and automated development workflows
- Deploy the application

## Current Status

Currently in development

The machine learning model has been developed with current work focusing on building the application itself.
